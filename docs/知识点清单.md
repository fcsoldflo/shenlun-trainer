## 第二批：P023–P058（只记新方法/新模板）

### 对策类
- **P026**：提出对策＝直接对策＋反推对策；反推前先“找谁定位、明确主题”。
- **P027**：反推对策＝行为做法＋问题关键词；问题的表现/原因/危害可转化为要点或好结果；题干只要求“建议”时只写对策。
- **P028｜提出对策常见问法（辨析，重点）**：
  1. 根据问题提出对策 → 概括归纳，只写对策；
  2. 材料提到若干问题，请就这些问题提出对策 → 问题＋对策；
  3. 根据问题提建议，要求概括问题简明扼要 → 问题＋对策；
  4. 梳理问题并提出解决建议 → 问题①②③＋对策①②③；
  5. 问题、建议一一对应/相对应 → ①问题：建议 ②问题：建议；
  6. 分析原因，提出解决建议 → 原因①②③＋对策①②③；
  7. 如何让……重新“乐”起来 → 推出对策。
- **P031｜“对策”要素考察情况辨析**：
  - 概括……有效举措 → 概括归纳，①②③；
  - 归纳概括…… → 分类归纳，总分结构；
  - 请你提出…… → 提出对策（“推着抄”）；
  - 谈谈……启示 → 启示（“推着抄”）。
- **P053**：写做法/对策时“找动词”，直接抄前面对应的动词；人员分工、团队划分可按主体分类。

### 综合分析
- **P032｜答案书写方式**：观点（如“我不支持”）＋解释＋原因＋危害＋因此对策，可**一段式、不分段**写完；词语类表格再次确认：贬义（表态/解释/原因/危害/对策）、褒义（表态/解释/原因/好处/问题/对策）、中性（表态/解释/原因/好处/坏处/对策）。
- **P034**：综合分析模板＝解释（优先去出处找含义）→原因→危害→因此对策；题干有“逻辑/层次”要求时要注意层次。
- **P035**：遇到不理解的引号词/生词，看上下文解释；要素之间有交叉时，写在哪一部分都可（“要素理解有交叉，写在哪都行”）。
- **P036**：中性词（如“黑科技”）模板＝解释＋原因＋好处＋坏处＋因此对策。
- **P038**：句子类模板＝解释＋分析（问题等）＋因此对策。
- **P042**：**忠于原文，先看原文**；句子类若展开分析的位置已够，最后“因此”是否写，看材料、看字数决定。

### 公文
- **P045｜全格式模板（宣传单）**：标题 → 称谓 → 第一段（铺垫＋表态＋承上启下）→ 第二段（主体：好处/做法/原因，一、二、三）→ 第三段（总结呼吁，自己写）→ 落款（单位＋日期）。
- **P048｜半格式模板（发言稿）**：标题 → 称谓 → 客气介绍身份＋铺垫＋表态＋承上启下 → 主体（总结座谈内容，材料给啥写啥）→ 总结呼吁。
- **P051｜无格式模板（宣传报道）**：标题 → 铺垫＋表态＋承上启下 → 从标题出发写“好做法＋好结果”（一、二、三）→ 总结呼吁。
- **P054｜无格式模板（案例介绍材料）**：标题 → 铺垫＋表态＋承上启下 → 做法（动词＋名词）一、二、三 → 总结呼吁。
- **P056｜无格式模板（发言提纲）**：标题 → 铺垫＋表态＋承上启下 → 经验（好做法＋好结果）一、二、三 → 总结呼吁。
- **P048/P056｜公文布局**：第二段占比最大；在保证第二段最大的前提下，部分内容写在哪可灵活安排。
- **P056**：公文题要求出现“逻辑/层次/分类”等词时，第二段要**分类扣帽**书写。
- **P055**：公文第一段可以用材料中“例子的问题”做铺垫。

## 第三批：P059–P116（116/116 已读完）

### 大公文 / 公文进阶
- **P063**：字数 **>600 字**按“大公文”处理；大公文第二段要**进一步分类扣帽**，分几类就分几段；第一段、最后一段可用自己的话适当润色，不影响得分。
- **P064**：提出对策性质公文（提案、建议书、工作建议、解决方案）——第二段提对策，第一段写问题（问题多时写 3–4 个）；反推＝行为做法＋问题关键词。
- **P066**：半格式讲话稿——客气介绍身份＋铺垫＋问题＋表态＋承上启下 → 提出对策（一、二、三）→ 总结呼吁；**发文对象/场景会影响要点提取**。
- **P068**：工作方案模板——标题 → 铺垫＋问题＋表态＋承上启下 → 提出对策 → 总结呼吁；按材料逻辑分类（如资料3/资料4各成一组）。
- **P094**：公文第一段“铺垫”优先抄与主题、场景关系最紧密的内容，1–2 句即可。
- **P095**：编者按单段模板——铺垫（背景/目的/意义）＋表态＋承上启下＋主体内容（做法）＋总结呼吁。
- **P097**：调研报告提纲——标题 → 铺垫＋问题＋承上启下 → 调研情况（好做法＋好结果）→ 总结。
- **P100**：短评模板——标题 → 铺垫＋表态＋承上启下 → 从题目出发写原因（一、二、三）→ 总结；**短评/时评/述评/评析第一段要表态**；表态特殊时＝回答题干疑问句；主体可按主体分类或材料逻辑分类。

### 作文
- **P069**：**主副标题**——主标题是中心思想，副标题解释说明主标题；副标题在主标题下第三个格子开始写破折号。结构行数：800–1000 字（起6/承6/转7×3/合4）；1000–1200 字（起7/承7/转8×3/合5）；“转”占最大部分，三个分论点占比大致相同。
- **P071–P073**：第一段背景引入四法——历史背景（抓时间词）、社会背景（抓社会现状，可适当引申）、名言背景（抓名人名言，可简单翻译）、时政背景（抓会议文件，精简表述）；配套话语模板见原页。
- **P074–P076**：**分论点三法**——
  1. 题干围绕中心词给出并列/递进（A、B、C），直接拆成三个分论点，不可改动；
  2. 题干没有，但出处材料是总结性/概括性/“高大上”材料——从出处材料找最宏观、最高频的三者并列/递进（三个词/三句话/三个自然段/三层意思）；
  3. 题干没有、出处材料也不是总结性/无并列/无出处——统筹全文（所有资料），找最宏观、最高频的并列作为分论点。
- **P104**：题干只给两个分论点（A、B）时，第三个分论点按关系补：
  - A、B 辩证统一/相辅相成 → 补 A＋B；
  - A、B 中有一个更强调 → 补更强调的那个；
  - 没有辩证统一、也没有更强调 → 到材料中补一个 C。
- **P101/P102/P105/P107/P115**：分论点实战例——虑/务/傲（成就伟大事业）；人生奖杯（个人/团队/国家）；流动的中国（科技/政策/开放）；“若云”情怀（信念/实干/担当）；家风（个人/社会/党内）。
- **P109**：分论点写意义——中心思想以“中心词＋好结果”呈现时可找意义；找不到意义仍写对策；行文框架同旧版（段1 6–7行、段2 7–8行、段3 7–8行、段4 3–8行、段5 问题4行、段6 衔接＋对策＋升华5行）。

### 概括归纳 / 要素
- **P078**：**原因要素灵活理解**——正面事例的原因，往往找“积极/好的表述”（好做法＋好结果）；反面事例的原因，往往找“负面/消极的表述”（问题）；原因还可分为内、外两个维度。
- **P080**：**要点不够时的操作**——① 案例型材料，前后有总结优先抄总结；② 总分关系优先抄总；③ 相同表述合并；④ 抓大放小，优先抄最满足、最契合题干问法的；⑤ 找对策：动词＋名词。
- **P081–P082**：变化题——过去/变化前（先找问题）＋现在/变化后（多为好做法＋好结果）；必抓时间词；格不够“前略后详”；写法一（过去①②③/现在①②③）、写法二（从……到……）；新变化只写现在/变化后。
- **P083–P084**：焦点题——焦点：……是否合理；正方/支持方/一方认为①②③，反方/反对方/另一方认为①②③；多个焦点分焦点①②写。
- **P085–P086**：特点题——人物＝名称＋品质＋做法＋好结果/贡献（顺序不限、点全即可、独特之处即答案点、格不够做法转品质）；事物＝好做法＋好结果。
- **P090**：多问题对策题——按“问题①→对策①、问题②→对策②”分层对应；直接对策优先抄，没解决的反推（行为做法＋问题关键词）。
- **P092**：变化类句子综合分析——表态＋解释＋“过去/变化前 vs 现在/变化后”＋因此；材料按段分层（举例/制度/技术/出行者）。
