《申论全书 · 训练器》分享说明

一、最快：直接发单文件
文件：申论全书_训练器_单文件版.html（约 145 KB）
- 电脑：微信/QQ 收到后，下载 → 双击，用 Edge/Chrome 打开。
- 手机：微信里点文件 → 右上角“…” → “用其他应用打开” → 选浏览器。
  如果打不开，改用下面的“发链接”方式。
- 不需要联网，学习进度保存在各自浏览器里。

二、发压缩包
申论全书_训练器_分享包.zip 内含：
- 单文件版 HTML
- 速记手册 PDF
- 本说明
对方解压后双击 HTML 即可；PDF 可直接打印。

三、发链接（朋友手机最方便）
任选其一：
1) Netlify Drop：打开 app.netlify.com/drop，把“申论全书_训练器”整个文件夹拖进去，
   得到 https://xxx.netlify.app 链接。
2) GitHub Pages：新建仓库 → 上传文件夹内所有文件（保持 assets、data 目录）→
   Settings → Pages → Deploy from branch → main / root →
   得到 https://用户名.github.io/仓库名/。
3) 国内访问：Gitee Pages（需实名）、腾讯云静态网站托管、阿里云 OSS 静态网站。
注意：上传的是“多文件版”整个文件夹（index.html + assets + data），不是单文件版。

四、同一 Wi-Fi 临时分享
双击“启动局域网分享.bat”，窗口会显示本机 IPv4。
朋友连同一个 Wi-Fi，浏览器打开 http://你的IPv4:8000
关闭窗口即停止。首次运行如弹出防火墙，选“允许访问（专用网络）”。

五、注意
- 学习进度存在每个人自己的浏览器里，互不影响，也不会同步。
- 手机用微信直接打开 HTML 可能被拦截，优先发链接，或用系统浏览器打开。
- PDF 只是打印版，交互功能在 HTML 里。
- 单文件版与多文件版内容一致；以后更新内容，重新生成单文件即可。
